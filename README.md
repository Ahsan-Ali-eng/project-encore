# Project Encore

## Mission

Project Encore is an AI-powered customer retention platform that helps local service businesses increase repeat customers through intelligent Email and SMS follow-up automation.

## Vision

Businesses shouldn't have to remember to follow up with every customer.

Encore automatically sends the right message, to the right customer, at the right time using AI-powered automation.

## Target Customers

- Auto Repair Shops
- Auto Detailers
- Dentists
- Chiropractors
- Salons
- Barbers
- Cleaning Companies
- HVAC Companies
- Pet Groomers

## Core Features (MVP)

- AI-generated follow-up campaigns
- Email automation
